# Chesa's label design sources

Original overworld label artwork and type source, drawn by Chesa for marcustay.net.
These files are the design source of truth behind `client/public/assets/overworld.png`.

Contents:
- `Portfolio Site_Labels.pdf`: the full labels sheet.
- `Portfolio Site_Labels_Individual.pdf`: labels as individual pieces.
- `BoldsPixels.ttf`: the pixel font used by the labels.
- `chesa-map.png`: the map rendered from the labels sheet (2176x1152), the basis of the live overworld image.

Rules (Marcus's call, do not change):
- `BoldsPixels.ttf` is for labels only. It is not a site UI font.
- The map ships without year subtitles under the building names.
- Do not redraw or "clean up" the lettering; ship Chesa's lettering as drawn.

Preserved here for the repo record only. Nothing in this folder is served by the site.
